# 계정·지표 코멘트 — 앱 전용 보충 규칙

계정 선정·색상 판단·코멘트 작성 규칙 본문은 위 스킬 원문(기초재무진단 Q1·Q2·Q3, 공통 작성 규칙)을
따른다. 이 문서는 그 규칙을 고객용 자동 생성 앱의 출력 형식에 맞추는 부분만 정한다.
스킬 원문과 충돌하면 출력 형식(1~3)은 이 문서를, 내용 판단은 스킬 원문을 따른다.

## 1. 출력 형식

- 결과는 `record_account_comments` 도구 한 번으로 기록한다. 표·설명문을 따로 출력하지 않는다.
- `bs_accounts` / `is_accounts`: 스킬 Q2-2에 따라 선정한 재무상태표·손익계산서 핵심 계정(각 20개 이내).
- `bs_indicators` / `is_indicators`: 전달된 지표 전부. 추가 선정이나 제외 없이 하나씩 코멘트를 단다.
- `color`는 스킬 색상 체계를 다음 값으로 적는다: 하늘색 → `sky`, 회색 → `gray`, 주황 → `orange`.
- `level`은 스킬 Level 기준의 1·2·3을 숫자로 적는다.
- Q3-2(압축)·Q3-3(품질 검토)은 기록 전에 스스로 수행하고, 고친 최종 코멘트만 기록한다.
  평가 결과(A)(B)(C)를 따로 출력하지 않는다.

## 2. 계정명 표기

`account`에는 전달된 데이터의 계정과목 표기를 한 글자도 바꾸지 않고 그대로 쓴다. 보고서가 이 값으로
원본 행을 다시 찾아 연도별 금액을 붙이므로, 표기가 다르면 그 계정의 금액이 빠진다.
로마자 대분류(Ⅰ. 유동자산 등)도 원본 표기를 따른다.

## 3. 분량

- 계정 코멘트: 40자 이내(스킬 Q3-1 출력 형식).
- 지표 코멘트: 50자 이내(스킬 Q4-2 출력 형식).
- 위험 계정(주황 Level 2~3)의 "사실. 관리 행동" 구조(스킬 Q3-1)는 두 마디로 써도 되지만 위 분량 안에 넣는다.

## 4. 앱에서 추가로 지키는 것

- 모든 연도 값이 0인 계정은 선정하지 않는다. 단 스킬 Q2-1 숨김 불가 필수 묶음(대분류 합계·총계,
  자본금, 매출액 등)은 0이어도 포함한다.
- 이 코멘트 뒤에 종합의견(ES)이 이 표를 근거로 작성된다. 코멘트끼리 같은 수치를 반복하지 않는다(스킬 Q3-2 ①).
