# 기초재무진단 통합 스킬

## 개요

알파브라더스 그로스파이낸스팀의 기초재무진단보고서 작성 워크플로우를 자동화한다.
재무제표 파일을 받아 계정 선정 → 코멘트 작성 → 재무지표 산출 → Executive Summary 생성까지 end-to-end로 처리하거나, 초안과 이사님 완성본을 비교 분석하여 피드백을 제공한다.

**이 파일은 단계별 라우터다.** 각 단계에서 무엇을 읽을지만 적는다. 규칙 본문은 `references/`에 있고, 해당 단계에 들어갈 때 그 파일을 읽는다. Q 번호(Q0-1, Q5-14 등)는 원래 번호를 그대로 유지하므로 파일 간 교차 참조는 번호로 찾는다.

---

## 0. 파일 입력 분기 (자동 판단)

파일이 업로드되면 즉시 아래 기준으로 모드를 결정하고 추가 질문 없이 실행한다.

| 입력 상태 | 모드 | 실행 내용 |
|---|---|---|
| 재무제표 파일 1개 (원본) | **Mode A** | Q1~Q5 순서로 재무분석 초안 생성 |
| 완성본 1개만 | **Mode G1** | ES 역추적 + Director's Logic 학습 |
| 초안 + 완성본 2개 | **Mode B** | G1~G3 비교 분석 전체 실행 |
| 텍스트 붙여넣기 | 내용 보고 A 또는 B 자동 분기 |

파일 내 고객사 산업·업종이 명시되지 않은 경우, 본문 단서로 업종을 식별하고 식별 근거를 1줄로 명시한다. 식별 불가 시 "업종 미확인"으로 표기하고 진행한다.

## 1. 작업 단계와 읽을 파일

### STEP 0 — 착수 전 필수 절차 (Q0, Mode A·B 공통) ★
기준자료 무조건 선독(Q0-1)과 ES 착수 전 4개 판정 확정(Q0-2). **건너뛰면 ES가 산업 맥락 없는 숫자 나열이 된다.** 기준자료 성격별 활용법(기준값표·산업별 참조표)도 같은 파일에 있다.
→ `references/preflight.md`

### STEP 1 — 재무제표 추출·검증 (Q1)
3개년 추출, 데이터 오류 검토, 적자·순손실 전환 시 원인 분해(Q1-3, 필수).
→ `references/statements-and-accounts.md`

### STEP 2 — 계정과목 선정 (Q2)
숨김 가능 계정과 숨김 불가 필수 묶음, 재무제표별 핵심 계정 20개 이내.
→ `references/statements-and-accounts.md`

### STEP 3 — 계정별 코멘트 (Q3)
색상 판단 4단계, Level 기준, 코멘트 작성·압축·품질 검토.
→ `references/account-comments.md` + `references/writing-rules.md`

### STEP 4 — 재무지표 산출·그래프 (Q4)
재무상태표·손익계산서 기반 각 5개 표준, 활동성 지표 기준 통일, 그래프 추천.
→ `references/ratios-and-charts.md`

### STEP 5 — Executive Summary (Q5)
쓰기 전에 Q0-2 4개 판정이 확정돼 있어야 한다. 작성은 구조 파일로, 다 쓴 뒤 검수는 검증 파일로 한다.
- Q5-1~Q5-12 3단락 사고·불릿 5개, 단락 패턴, 압축, 화살표·단위·약어 표기 → `references/es-structure.md`
- Q5-13~Q5-20 전칭 표현 검증, 근거 소재, 기준값 등급, 고객 대면 톤, 법정 형태, 산업 특성, 용어 정렬 → `references/es-verification.md`
- 표현 금지·허용 목록 → `references/writing-rules.md`

### STEP 6 — 엑셀 산출물 (확정 형식)
Graph·Analysis·RAW 3시트, 숨김 처리, 원본 대사 선행, 이사님 파일 위 수정, 문서 간 일관성, 업종 비교·외부 정보 처리.
→ `references/excel-output.md`

RAW 시트는 회사와 무관하게 고정 형식 하나로만 만든다(머리글·열 순서·블록 순서·부호·검증 블록).
→ `references/raw-format.md`

Graph 차트는 제목 = 옆 원천 표의 제목, 범례 = 표의 행 머리글(셀 참조).
→ `references/ratios-and-charts.md` 「차트 제목·범례 = 원천 표」

파일을 넘기기 전에 형식 검사를 돌린다. 이상이 있으면 종료 코드 1.

```bash
python scripts/check_workbook.py ㈜회사명_기초재무분석_YYYYMMDD.xlsx
```

검사 스크립트를 고친 뒤에는 `python tests/test_check_workbook.py`로 "전체 통과"를 확인한다.

## 2. 어느 단계에서든 지키는 절대 규칙

상세 근거는 괄호 안 번호의 파일에 있다. 아래는 빠뜨리면 산출물이 바로 틀어지는 항목만 모은 색인이다.

- 기준자료는 폴더 나열로 없음을 확인한 뒤에만 건너뛴다 (Q0-1)
- 추정값을 만들지 않는다. 데이터 없음은 NA, 확인 안 된 항목은 "확인 불가" (Q1-1·Q1-2)
- 적자 원인은 증감 기여도 1위 항목을 지목한다. 나쁜 지표를 주범으로 단정하지 않는다 (Q1-3·Q5-3)
- 셀 코멘트는 명사형 단문 1문장, 화살표 비율 표기는 재무제표별 2개까지 (Q3-1)
- ES 화살표는 전체 2개까지, 단위는 한국식 억+천만, 영어 약어는 한글로 (Q5-8·Q5-9·Q5-10)
- ES 수치의 근거는 고객이 받는 보고서 지면 안에 있어야 한다. Graph 시트·숨김 행은 근거가 아니다 (Q5-14)
- 전칭 표현(전액·모두·없이 등)은 해당 계정 잔액 0 확인 후에만 쓴다 (Q5-13)
- 기준값표 등급 명칭을 임의로 올리거나 내리지 않는다 (Q5-15)
- 수정은 이사님이 수정한 파일 위에서 한다. 파일을 처음부터 다시 만들지 않는다 (엑셀 산출물 형식)
- RAW는 고정 형식 하나로만 만들고, 원본 대사 차이가 0이 아니면 Analysis에 들어가지 않는다 (raw-format.md)
- 차트 제목은 원천 표 제목과 같은 글자, 범례는 표 행 머리글 셀 참조. 메시지 문장을 제목에 넣지 않는다 (Q4-4)

## 3. 출력 원칙

- 표 우선, 줄글은 표 사이 연결 설명에만 제한적 사용
- Excel/Notion 복붙 가능한 형태 유지
- 외부 지식(거시·산업·법률) 기반 추론은 "(추론)" 라벨 명시

## 4. 다른 스킬과의 관할

- **management-pl** — 관리회계 PL 워크북이 올라왔다고 이 스킬의 Mode A를 자동 실행하지 않는다. 사용자가 진단보고서를 명시적으로 요청할 때만 쓴다. 두 스킬은 단위(원 단위 vs 억+천만)와 서술 방식이 다르므로 한 산출물에 섞지 않는다.
- **executive-summary** — 같은 이사님 편집 기준으로 ES를 다룬다. 이 스킬의 Q5와 내용이 겹친다(5장 참조).

## 5. 알려진 미해결 과제

- executive-summary 스킬과 Q5 규칙 중복 — 같은 기준이 두 곳에 있어 한쪽만 갱신되면 어긋난다. 어느 쪽을 기준본으로 둘지, 충돌 시 우선순위를 아직 정하지 않았다
- 그래프 개수 기준 두 가지 공존 — 보고서용 2~3개(Q4-4)와 엑셀 Graph 시트 5개(엑셀 산출물 형식). Q4-4에 구분 문장이 있으나 요청 문구만으로 어느 쪽인지 갈리지 않을 수 있다
- RAW 고정 형식은 기존 규칙(원 단위·소계 수식·차감 양수·원본 대사 선행)을 바탕으로 정한 안이다. ㈜더밤부_기초재무분석_20261006.xlsx 실물과 열 배치를 대조하지 않았다
- `check_workbook.py` [G1]은 차트 제목이 Graph 시트의 **어느** 셀 글자와 일치하는지만 본다. 바로 옆 표인지까지는 판정하지 못한다
- (2026-10-13 검토) executive-summary와 실제 어긋난 지점 — ES 분량(700~1,000자 vs ~1,100자), "~필요합니다" 종결(Q5-7 "로만 마무리" vs 저쪽 "단독 종결 1문장만"), 차트 작성(엑셀 Graph 5개 직접 작성 vs 저쪽 "권고만"). 저쪽 v1.2 기준(기존 운영 체계 권고 금지·미래 문장 긍정 프레이밍·"(제공해주신 자료 기반)" 병기)이 Q5에 없고, Q5-13·15·17·20은 저쪽에 없다. 제안: executive-summary를 ES 기준본으로 두고 이쪽 고유 항목을 옮긴 뒤 STEP 5는 그 스킬을 가리키게 한다
- (2026-10-13 검토) 스킬 내부 충돌 — ① Q3-1 "1문장 원칙" vs 같은 절 예시가 두 문장 ② "비율 우선·기본 탑재" vs 화살표 비율 재무제표별 2개 vs "절대금액만 기술 금지" ③ ES 첫 문장 Q5-2 "반드시 정체성" vs Q5-12 "공유해 주신 데이터를 근거로 하면" 허용 ④ Q5-12 단락당 4~5문장(최대 15) vs 피동 종결 기준 20~27문장 전제 ⑤ 차트 색상에 진단 색상(판정 의미) 허용
