# 계정별 코멘트 작성

> SKILL.md STEP 3(Q3)에서 참조한다. 표현 금지·허용 목록은 `writing-rules.md`를 함께 본다.

## Q3. 계정별 코멘트 작성

**Q3-1. 코멘트 초안**
코멘트 작성 전 각 계정마다 아래 색상 판단 4단계를 수행한다.

색상 판단 4단계:
1. 지표의 '질' 확인 (유동비율↑이라도 재고·채권 증가이면 현금여력 재확인)
2. 지속가능성 확인 ("외부 환경 악화에도 이 수치가 유지되는가?")
3. 현금 영향 확인 (재고 지연·채권 지연·이자 부담 증가 시 Level 상향 검토)
4. 원인 층위 확인 (숫자 조정으로 끝나는가 vs 관리체계 부재인가)

색상 체계:
| 색상 | 의미 | 헥스코드 |
|---|---|---|
| 하늘색 | Strength (강점·긍정) | #DAEEF3 |
| 회색 | Neutral (중립·현상) | #F2F2F2 |
| 주황 | Warning (경고·위험) | #FDE9D9 |

Level 기준:
- Level 1 관찰: 안정 범위 내 소폭 변화 → 회색 또는 하늘색
- Level 2 주의: 전년·업종 대비 10~30% 변동 → 회색 또는 주황
- Level 3 경고: 이자보상배율 1미만 / 유동비율 100%미만 / 런웨이 6개월 이하 / 원가율 100% 초과 → 주황

코멘트 작성 규칙:
- **비율 우선**: "(매출대비 X%→Y%)" 형식으로 비율 변동을 기본 탑재. 절대금액만 기술 금지.
  - **단, "(매출대비 X%→Y%)" 화살표 비율 표기는 재무상태표 코멘트 전체에서 2개, 손익계산서 코멘트 전체에서 2개로 제한.** 나머지는 절대금액 대비(A→B억 원) 또는 증감률(%) 형식 사용.
- **팩트만 기술**: 확인되지 않은 원인 추정 금지. "~포함 추정", "~혼재 추정" 표현 금지. 수치 사실만.
- **명사형 단문 종결**: "~니다", "~판단됩니다", "~필요합니다" 종결 금지. "[원인]으로 인한 [결과]" 명사형으로 끝낼 것.
- **1문장 원칙**: 코멘트 전체를 1문장으로 압축.
- **위험 계정은 행동으로 끝맺는다** (더블유아일랜드 반영): 현금·재고·차입금 등 주황(Level 2~3) 핵심 계정은 "사실 + 관리 행동" 구조로 쓴다. 관리 행동은 명사형("점검 필요", "모니터링 필요")으로 붙인다.
  - ✗ "6.6억에서 11.3억으로 71.6% 증가, 평가충당금 3년째 동일" → ✓ "6.6억에서 11.3억으로 71.6% 증가. 장기 재고 등 모니터링 필요"
  - ✗ "2년간 차입 15.5억 유입에도 5.2억으로 감소, 단기차입금에 미달" → ✓ "2년간 차입 유입에도 5.2억으로 감소. 단기 유동성 자금 점검 필요"
  - 회색·하늘색 계정은 기존대로 사실만 쓴다.

출력 형식 (Excel 복붙 가능):
`계정과목 | Level | 색상 | 헥스코드 | 코멘트(40자 이내)`

**Q3-2. 코멘트 압축 및 거시화**
① 중복 제거: 동일 방향 코멘트 통합. **같은 수치를 다른 계정·지표 코멘트나 ES에서 반복하지 않는다** (예: 차입 15.5억이 차입금의존도 코멘트에 있으면 현금 코멘트에서는 뺀다. 상품평가충당금 사실이 ES에 있으면 재고 코멘트에서는 뺀다).
② 표현 압축: 절반 이내 축약, 핵심 유지
③ 거시화: 개별 숫자 나열 → 구조적 방향성 중심
④ 계정 수 유지, 코멘트만 조정
⑤ **양호 항목 vs 문제 항목 분량 차등**: 양호한 영역(하늘색·회색 Level 1)은 짧게, 변화·전환·보완 영역(주황 Level 2~3 또는 핵심 발견)은 구체적 수치 동반
유지 필수: 수치 대비(A→B) 표현 최소 1개, Level·색상 유지

**Q3-3. 코멘트 품질 검토**
① 정확성: 수치·방향 데이터 일치 여부
② 색상 적정성: 표면 수치가 아닌 구조 반영 여부
③ 균형성: 긍정/중립/부정 분포 편중 여부
④ 과잉 경보: 5% 이내 변화에 "급증/급락" / Level 1에 "우려/경색/잠식" 사용 여부
⑤ 누락 계정: 현금흐름 중요 계정 누락 여부

출력: (A) 평가 결과 (B) 수정 필요 코멘트+수정안 (C) 추가 필요 계정+보완 코멘트
