# 착수 전 절차와 기준자료

> SKILL.md STEP 0에서 참조한다. Mode A·B 공통으로 가장 먼저 읽는다.

**어떤 모드든 아래 두 단계를 먼저 끝낸다. 건너뛰면 ES가 산업 맥락 없는 숫자 나열이 된다.**

## Q0-1. 기준자료 무조건 선독

작업 폴더·프로젝트 폴더에 **기준자료 성격의 파일이 있으면 예외 없이 먼저 읽는다.** 파일명·경로는 프로젝트마다 다르므로 고정하지 않고, 폴더를 나열해 아래 성격의 파일을 찾아 읽는다.

| 찾을 자료 | 쓰이는 곳 |
|---|---|
| 기준자료 요약·색인 문서 (있으면 이것부터) | 전체 기준 파악 |
| 재무지표 기준값표 (안정성·유동성·활동성·수익성·성장성 등급 범위) | Q4 지표 판정 |
| 산업맥락·산업별 참조표 (산업군별 결정 KPI·비용구조·Red Flag) | Q2 계정 선정, Q5-18 산업 특성 반영 |
| 보고서 템플릿 (섹션 구성·사전 검토사항 문항·채점 방식·부록 성장단계표) | 산출물 골격 |
| 업종코드↔표준산업분류 연계표 | 업종 → 산업군 매핑 |

해당 파일이 없음을 **폴더 나열로 확인한 뒤에만** 스킬 내장 기준으로 진행한다. "없을 것 같다"는 추측으로 건너뛰지 않는다.

## Q0-2. ES 착수 전 4개 판정 확정

Q5를 쓰기 전에 아래 4개를 확정하고 각 판정 근거를 1줄로 남긴다.

| # | 판정 | 근거 자료 |
|---|---|---|
| ① | **산업군 분류** + 그 산업군의 결정 KPI 2개 | 산업별 참조표 (제조 / IT·SaaS·플랫폼 / B2B 서비스·아웃소싱 / 유통·도소매 / 건설·수주 / F&B) |
| ② | **성장단계 Lv1~Lv4** | 보고서 템플릿 부록 성장단계표 (인원·매출 기준) |
| ③ | **사전 검토사항 점수** | 템플릿 채점 방식 그대로. 임의 환산 금지 |
| ④ | **지표별 기준값 등급** | 기준값표의 등급 명칭을 그대로 사용 |

① 없이 쓰면 ES에 산업 특성이 빠진다. ② 없이 "성장기" 같은 단계 표현을 쓰면 근거 없는 단정이 된다.

## 기준자료 성격별 활용법

**Q0-1에 따라 기준자료는 착수 전 무조건 먼저 읽는다.** 파일명·경로는 프로젝트마다 다르므로 아래는 성격별 분류이며, 실제 파일은 작업 폴더·프로젝트 폴더를 나열해 찾는다.

| 자료 성격 | 용도 | 읽는 시점 |
|---|---|---|
| 기준자료 요약·색인 문서 | 전체 기준 한눈에 파악. 있으면 이것부터 | **Q0-1 (최우선)** |
| 재무지표 기준값표 | 안정성·유동성·활동성·수익성·성장성 등급 범위 | Q4 지표 산출·판정 전 |
| 산업맥락·산업별 참조표 | 산업군별 Core Mechanism·결정 KPI·비용구조·Red Flag | Q2 계정 선정 전, Q5-18 산업 특성 반영 |
| 보고서 템플릿 | 섹션 구성, 사전 검토사항 문항·채점 방식, 부록 성장단계표 | Mode A 최초 실행 시, Q0-2 ②③ |
| 업종코드↔표준산업분류 연계표 | 업종코드 → KSIC → 산업군 매핑 | Q0-2 ① 산업군 분류 |

산업맥락 참조표 활용법:
- 고객사 업종 확인 후 `Sheet: 산업별 참조표`에서 해당 산업군의 Core Mechanism, 결정 KPI, 비용 구조 특징 식별
- Red Flag 기준으로 Level 3(주황) 판단 보완. 단 **흑자·무차입 기업에 런웨이 경보를 그대로 적용하면 과잉 경보**가 되므로, 색상은 중립으로 두고 코멘트에 사실만 적는 선택지를 함께 검토한다
- B2B 서비스 아웃소싱: 인건비율·1인당 매출·런웨이 최우선 / 제조업: 가동률·수율·재고회전율 최우선

재무지표 기준값표 활용법:
- 기준값 범위(안정/주의/위험)로 Level 판정. **등급 명칭을 임의로 상·하향하지 않는다** (Q5-15)
- 이자보상비율 1미만 → 즉시 Level 3, 유동비율 100%미만 → Level 3 기본값
- 단년 재무제표만 있으면 성장성 지표는 "산출 불가"로 명시하고, 로데이터 산출물에서는 값 없는 행을 삭제한다
