# 엑셀 산출물 형식 (확정)

> SKILL.md STEP 6에서 참조한다. 고객사별 프로젝트 지침이 있으면 그것이 우선한다.

기초재무분석 엑셀은 ㈜더밤부_기초재무분석_20261006.xlsx 형태로 작성한다. 고객사별 프로젝트 지침이 있으면 그것이 우선한다.

| 항목 | 기준 |
|---|---|
| 시트 구성 | Graph · Analysis · RAW 3개 시트 |
| RAW | **고정 형식 `raw-format.md`를 따른다.** 세부 계정은 원 단위 입력, 소계·합계는 수식. 차감계정(충당금·감가상각누계액)은 양수 입력 후 합계에서 차감 |
| Analysis | RAW 연결. 손익계산서를 재무상태표보다 먼저 배치(원인 → 결과 순서). 핵심 계정 옆 색상 코멘트, 각 재무제표 아래 비율 블록, [분석 전제], 색상 범례 |
| 숨김 처리 | 중요하지 않은 계정과목 행과 재무지표 행을 그룹 숨김(＋로 펼침). 재무지표는 블록별 5개만 노출. Q2-1 필수 묶음과 Level 3 경고 지표(현금보유월수 등)는 노출 |
| Graph | 회사별 핵심 그래프 5개를 직접 선정·작성. 메시지가 겹치는 그래프는 교체. **차트마다 옆에 원천 표를 두고 차트 제목 = 표 제목, 범례 = 표 행 머리글(셀 참조)** (`ratios-and-charts.md` 「차트 제목·범례 = 원천 표」). 출처 표기 |
| 착수 전 | 제공 원본(PDF 등)과 RAW 총액을 먼저 대사하고 오류·수정재작성 여부를 보고한 뒤 진행 |
| 수정 시 | 이사님이 수정한 파일 위에서 고친다. 숨김·색상·차트 등 이사님 편집을 보존하고, 파일을 처음부터 다시 생성하지 않는다 |

**문서 간 일관성 점검** (더블유아일랜드 반영)
- 같은 지표를 문서마다 다른 정의로 쓰지 않는다. 예: 광고 1원당 매출(전체 매출 기준 3.1원) vs ROAS(컨설팅 제외 브랜드 매출 기준 2.9배), 공헌이익률의 변동비 범위(지급수수료·대손상각비 포함 여부).
- 회사명 표기를 모든 시트 제목·파일명에서 확인한다(예: "더블유아이일랜드" 오타).

**업종 비교**
- 업종 평균은 회사 수치와 같은 기간일 때만 코멘트·ES에 쓴다. 기간이 다르면(회사 2025 vs 업종 2024) 비교하지 않고 회사 자체 추이로 쓴다. 업종 평균 출처는 [분석 전제]에만 남긴다.

**외부 정보**
- 외부 신용평가 등급·점수 변동(CREPORT 등)은 [분석 전제]에만 적고, 고객 보고서의 코멘트·ES에는 쓰지 않는다.
- 회사 제공 자료(IR·체크리스트·시스템 스크린샷)에서 가져온 정보는 [분석 전제]에 "회사 제공(미검증)"으로 출처를 남긴다.

**산출물 검사** — 파일을 넘기기 전에 돌린다. RAW 고정 형식과 Graph 제목·범례 규칙을 검사하고, 이상이 있으면 종료 코드 1.

```bash
python scripts/check_workbook.py ㈜회사명_기초재무분석_YYYYMMDD.xlsx
```
