# Mode B — 초안·완성본 비교 분석 (G 시리즈)

> SKILL.md Mode B에서 참조한다. 완성본만 있으면 G1, 초안과 완성본이 함께 있으면 G1~G3.

명령 인덱스:

| 번호 | 작업명 | 필요 입력 |
|---|---|---|
| G1-1 | ES 작성 논리 역추적 | 완성본만 |
| G1-2 | 재무분석 코멘트 구조 분석 | 완성본만 |
| G1-3 | 그래프 완성도 분석 | 완성본만 |
| G2-1 | 색상/판단 차이 분석 | 초안+완성본 |
| G2-2 | 코멘트 텍스트 차이 분석 | 초안+완성본 |
| G2-3 | 그래프 차이 분석 | 초안+완성본 |
| G2-4 | 종합 비교표 (ES·코멘트·그래프 통합) | 초안+완성본 |
| G3-1 | Director's Logic 패턴 추출 | G2 결과 보유 |
| G3-2 | 종합 피드백 + 액션 아이템 | G2 결과 보유 |

호출 방식: 번호("G2-2") 또는 자연어("비교표 만들어줘", "ES 역추적해줘")

**G1-1: ES 역추적 분석**
출력: (A) 작성 논리 흐름도 (B) 문단별 구조 분석표 (C) 핵심 기법 3가지 (D) 다음 ES 작성 체크리스트

분석 5차원:
① 구조: 강점→리스크→시나리오 흐름 설계
② 5대 테마 커버리지: 성장/수익/운전자본/레버리지/관리체계 순서와 누락 여부
③ 문단 공식: Fact→Diagnosis→Impact→Control 중 어떤 구조를 따르는가
④ 수치 활용: 어떤 숫자를 '좌표'로 썼고 어떻게 Insight와 연결했는가
⑤ 톤 설계: 리스크 표현 수위가 Level 판단과 일치하는가

**G2 시리즈: 비교 분석**
핵심 출력:
- Executive Gap Analysis 요약표: 판단 감도 / 리스크 해석 깊이 / 톤·표현 수위 비교
- 항목별 비교표: 초안 내용 | 완성본 내용 | 변경 의도 추론 | 핵심 격차

**G3-1: Director's Logic 패턴 추출**
G2 결과 전체에서 이사님의 반복적 판단 패턴을 추출.
출력: (A) 패턴 목록 (B) 각 패턴의 적용 조건 (C) 내 작성에 적용할 체크리스트

**G3-2: 종합 피드백**
출력: 강점 / 보완점(항목+방향) / 추가 분석 제안 / Director 관점 1줄 진단
