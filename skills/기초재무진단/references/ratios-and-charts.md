# 재무지표 산출과 그래프

> SKILL.md STEP 4(Q4)에서 참조한다. 지표 판정 등급은 기준값표를 따른다(`es-verification.md` Q5-15).

## Q4. 재무지표 산출 및 시각화

### Q4-1. 재무지표 산출 원칙

재무상태표 기반 / 손익계산서 기반 구분, 각 5개 내외.
4개 관점 균형: 성장성 / 수익성 / 안정성 / 활동성

**재무상태표 기반 5개 표준 (대부분 케이스 적용)**

| 관점 | 지표 | 계산식 |
|---|---|---|
| 성장성 | 총자산증가율 | (당기-전기)/전기 |
| 안정성 | 부채비율 | 총부채/자기자본 |
| 안정성 | 차입금의존도 | 총차입금/총자산 |
| 유동성 | 유동비율 | 유동자산/유동부채 |
| 활동성 | 현금전환주기(CCC) | 매출채권 회수기간 + 재고자산 회전일수 - 매입채무 결제기간 |

**손익계산서 기반 5개 표준**

| 관점 | 지표 | 계산식 |
|---|---|---|
| 성장성 | 매출성장률 | (당기-전기)/전기 |
| 수익성 | 매출총이익률 | 매출총이익/매출액 |
| 수익성 | 영업이익률 | 영업이익/매출액 |
| 수익성 | ROA | 순이익/총자산 |
| 안정성 | 이자보상배수 | 영업이익/이자비용 |

**활동성 지표 산출 기준 통일 (필수)**

활동성 지표(DSO·DIO·DPO·CCC)는 반드시 **하나의 기준으로 통일**한다. 혼합 사용 금지.

| 기준 | 장점 | 적용 권장 |
|---|---|---|
| 기말 잔액 기준 | 직관적, 2023년부터 산출 가능 | **표준 권장** |
| 평균 잔액 기준 | 학술적 정확 | 외부 보고서 비교 시 |

기말 기준 산식:
- 매출채권 회수기간 = (매출채권 × 365) ÷ 매출액
- 재고자산 회전일수 = (재고자산 × 365) ÷ 매출원가
- 매입채무 결제기간 = (매입채무 × 365) ÷ 매출원가

### Q4-2. 출력 형식

`지표명 | 계산식 | 연도별 결과값 | 기준값/평가 | 코멘트(50자 이내)`

### Q4-3. 추가 판단

- 영업이익 관련 지표 포함 시 → 원가율 또는 판관비율 병기
- 유동비율↑이면 → 당좌비율 또는 재고 의존도 함께 산출
- 수익성 지표에 본업 마진 분리 (제품 vs 공사 vs 서비스) 권장
- 차입금의존도와 이자보상배수는 항상 함께 산출 (만기·상환력 동시 진단)

### Q4-4. 그래프 추천 (메시지 강화용 2~3개) ★

**그래프는 백화점식 나열 금지. ES 핵심 메시지를 강화하는 2~3개만 선정.**

단, 기초재무분석 엑셀의 Graph 시트는 `excel-output.md`(「엑셀 산출물 형식」)에 따라 회사별 핵심 그래프 5개를 직접 만든다(고정 지표 아님). Graph 시트는 보고서 지면에 들어가지 않으므로 ES 근거로 쓰지 않는다(Q5-14).

선정 우선순위 (Director 기준):
1. ES 인사이트 단락의 수익성 메커니즘 (원가율 vs 판관비율 시소)
2. ES 1단락 또는 인사이트의 자본 구조 변화
3. (선택) ES 보완사항과 직결되는 차트

표준 그래프 5종 후보:

| # | 차트 | 유형 | 데이터 | 메시지 | 채택 우선순위 |
|---|---|---|---|---|---|
| 1 | 매출 구성 변화 | 누적 세로 막대 | 제품/공사/SW 매출 | 사업 구조 전환 | 중 |
| 2 | 수익성 시소 | 선 그래프 3선 | 원가율/판관비율/영업이익률 | 영업이익률 유지 메커니즘 | ★ 최우선 |
| 3 | 자본 구조 추세 | 콤보 (막대+선) | 부채총계/자본총계/부채비율 | 자본 확충 vs 부채 증가 | ★ 최우선 |
| 4 | 현금·유동성 풍부화 | 콤보 (막대+선) | 가용현금/유동비율/당좌비율 | 단기지급 부담 소멸 | 하 |
| 5 | 차입금 만기 구조 | 누적 막대 | 단기차입/장기차입 | 만기 재편 + 순증 | 하 |

채택 기본값: **2번 + 3번 (수익성 시소 + 자본 구조)**.

ES에 매출 구성 전환이 핵심 메시지면 1번 추가. 보고서 본문 분량 여유 있을 때만.

**차트 작성 공통 가이드**

| 항목 | 권장 사항 |
|---|---|
| 차트 제목 | **옆 원천 표의 제목과 글자 그대로 일치** (아래 「차트 제목·범례 = 원천 표」). 메시지 문장을 제목에 넣지 않는다 |
| 폰트 | Arial 또는 맑은 고딕, 10~11pt |
| 색상 | 진단 색상 또는 회사 톤 통일 (남색 #1F4E78 계열 권장) |
| 격자선 | 가로 격자선만 흐리게, 세로 격자선 제거 |
| 데이터 라벨 | 시작점·종료점·변곡점만 표기, 모든 점 표기 X |
| 단위 표기 | 축 제목에 단위 명시 "(단위: 억)" |
| 범례 | 상단 또는 우측, 작게. **항목명은 원천 표의 행 머리글(지표명·계정명)을 셀 참조로 연결** |
| 출처 | 차트 하단에 "출처: 표준재무제표 3개년" 명기 |

**차트 제목·범례 = 원천 표 (2026-10-13 확정)** ★

Graph 시트의 모든 차트는 바로 옆에 원천 표를 두고, 차트의 글자는 그 표에서만 가져온다. 차트 제목·범례가 표와 다르면 읽는 사람이 차트와 표를 같은 데이터로 대응시키지 못한다.

| 요소 | 규칙 | 예 |
|---|---|---|
| 원천 표 위치 | 차트 왼쪽에 둔다. 표 맨 위 셀에 표 제목, 그 아래 머리글 행(연도), 그 아래 계열별 1행 | — |
| 표 제목 | 핵심 지표명·지표 묶음명을 쓴다. 메시지 문장은 쓰지 않는다 | `수익성 지표`, `자본 구조`, `차입금 구성` |
| 차트 제목 | 표 제목 셀과 **같은 글자**. 띄어쓰기·괄호·단위 표기까지 같게 | 표 `수익성 지표` → 차트 `수익성 지표` |
| 범례(계열 이름) | 표의 행 머리글 셀을 **셀 참조로** 연결한다. 범례 칸에 글자를 직접 타이핑하지 않는다 | 계열 이름 = `=Graph!$B$5` (값 `영업이익률`) |
| 지표명 표기 | 행 머리글은 Analysis 시트·Q4-1 표의 지표명과 같은 표기를 쓴다. 약어·별칭 금지 | `매출총이익률` (✗ GPM, ✗ 매출이익률) |
| 표 값 | Analysis 또는 RAW를 참조하는 수식. 숫자를 직접 입력하지 않는다 | — |

메시지는 차트 선정 기준(위 5종 후보표의 "메시지" 열)으로만 쓴다. 제목에서 빠진 메시지는 ES와 본문 코멘트가 전달한다.

`scripts/check_workbook.py`가 차트 제목이 Graph 시트의 셀 글자와 일치하는지, 계열 이름이 셀 참조인지 검사한다.
