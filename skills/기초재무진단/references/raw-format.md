# RAW 시트 고정 형식

> SKILL.md STEP 6에서 참조한다. 기초재무분석 엑셀의 RAW 시트는 회사와 무관하게 이 형식 하나로만 만든다.

RAW는 원본 재무제표를 옮겨 적는 시트다. 해석·판단·서식은 Analysis가 맡고, RAW는 **원본과 1:1 대사가 되는 것**만 목표로 한다. 회사마다 열 위치·머리글·부호가 달라지면 Analysis 참조 수식과 원본 대사를 매번 새로 확인해야 하므로 형식을 고정한다.

고객사별 프로젝트 지침이 다른 RAW 형식을 정하고 있으면 그것이 우선하며, 그 사실을 답변에 밝힌다.

## 1. 시트 골격

| 위치 | 내용 (글자 그대로) |
|---|---|
| 시트명 | `RAW` |
| A1 | `{회사명} 표준재무제표 RAW` — 회사명은 파일명과 같은 표기 |
| A2 | `(단위: 원)` |
| A3 | `출처: {원본 자료명}, {발급일 또는 수령일}, 원본 단위 {원/천원/백만원}` |
| 4행 | 빈 행 |
| 5행 | 머리글 (2절) |
| 6행~ | 재무상태표 블록 → 빈 행 1개 → 손익계산서 블록 → 빈 행 1개 → 검증 블록 |

## 2. 머리글 (5행)

| 열 | 머리글 | 넣는 값 |
|---|---|---|
| A | `구분` | `재무상태표` / `손익계산서` / `검증` 중 하나. 모든 행에 반복 기입 |
| B | `계정과목` | 원본 표기 그대로 (3절) |
| C | `행유형` | `합계` / `소계` / `세부` / `차감` / `검증` 중 하나 |
| D부터 | 연도 (예: `2023`, `2024`, `2025`) | 숫자형 연도. **오래된 순(좌) → 최신(우)**. 원본에 있는 연도만 만든다 |
| 연도 다음 열 | `비고` | 일회성 라벨(보조금·처분손익·전기오류수정 등), `원본 공란`, 원본 대사 메모 |

연도 열 수는 원본에 따라 1~3개로 달라질 수 있다. 연도 열 사이에 다른 열을 끼우지 않는다.

## 3. 행 작성 규칙

- **블록 순서는 재무상태표 → 손익계산서로 고정한다.** 원본 문서 순서와 같아야 대사가 쉽다. Analysis의 손익계산서 우선 배치는 Analysis에서만 한다.
- **계정과목은 원본 표기·원본 순서를 그대로 쓴다.** 로마자 번호, 괄호, `(결손금)` 같은 병기를 지우지 않는다. 통합·축약·이름 변경 금지 (Q1-1). 계층은 공백 문자가 아니라 셀 들여쓰기 서식으로 표현한다.
- **숨김 판단(Q2-1)은 RAW에 적용하지 않는다.** RAW에는 원본의 모든 계정이 있어야 하고, 숨김은 Analysis에서 한다.
- `세부`·`차감` 행은 값을 입력한다. `소계`·`합계` 행은 수식으로 계산한다. 소계·합계에 숫자를 직접 넣지 않는다.
- `차감` 행(대손충당금, 감가상각누계액, 정부보조금 등)은 **양수로 입력**하고 상위 소계 수식에서 뺀다.
- 손익계산서의 이익 행(매출총이익, 영업이익, 법인세비용차감전순이익, 당기순이익)은 `합계` 또는 `소계` 수식이다. 손실이면 수식 결과가 음수로 나온다. 비용 행은 양수로 입력한다.
- 이익잉여금이 결손이면 음수로 입력한다.

## 4. 숫자

- **원 단위 정수**로 입력한다. 원본이 천원·백만원 단위면 원 단위로 환산해 넣고, 원본 단위는 A3에 남긴다.
- 원본에 금액이 없는 칸은 **빈칸으로 둔다. 0을 입력하지 않는다.** 원본에 0이 적혀 있으면 0을 입력한다. 빈칸으로 둔 행은 비고에 `원본 공란`을 적는다. 추정값을 만들지 않는다 (Q1-1).
- 표시 형식은 `#,##0;-#,##0`으로 통일한다.

## 5. 서식

| 항목 | 기준 |
|---|---|
| 글꼴 | 맑은 고딕 10pt, 시트 전체 동일 |
| 글자색 | 입력값(`세부`·`차감` 행 숫자) 파란색, 수식 검정 |
| 머리글 | 5행 굵게, 아래 테두리 |
| 틀 고정 | `D6` (머리글과 A~C열 고정) |
| 열 너비 | A 10, B 30, C 8, 연도 열 16, 비고 30 |
| 금지 | 병합 셀, 숨김 행·열, 그룹(윤곽), 채우기 색(진단 색상은 Analysis 전용), 블록 중간의 메모 행 |

## 6. 검증 블록

손익계산서 블록 아래에 빈 행 1개를 두고 다음 5행을 둔다. A열 `검증`, C열 `검증`.

| B열 계정과목 | 각 연도 열 |
|---|---|
| `대차 차이` | `자산총계 − (부채총계 + 자본총계)` 수식. 0이어야 한다 |
| `원본 자산총계` | 원본 금액 입력 |
| `자산총계 대사 차이` | `RAW 자산총계 − 원본 자산총계` 수식. 0이어야 한다 |
| `원본 당기순이익` | 원본 금액 입력 |
| `당기순이익 대사 차이` | `RAW 당기순이익 − 원본 당기순이익` 수식. 0이어야 한다 |

차이가 0이 아니면 Analysis 작업에 들어가지 않는다. 엑셀 산출물 형식의 "착수 전 원본 대사"가 이 블록이다. 원본 자체의 합계 오류가 원인이면 비고에 적고 보고한다 (Q1-2).

## 7. 수정할 때

- Analysis가 RAW 셀을 직접 참조하므로, Analysis 연결 이후 RAW에 행을 끼우거나 지우면 참조가 어긋난다. 수정재작성 등으로 계정이 추가되면 행을 넣은 뒤 Analysis 참조를 다시 점검한다.
- 이사님이 수정한 파일 위에서 고친다는 원칙(엑셀 산출물 형식)은 RAW에도 적용된다.

## 8. 검사

`scripts/check_workbook.py`가 1~6절 중 기계적으로 판정할 수 있는 항목(시트명, 단위, 머리글, 연도 순서, 구분·행유형 값, 소계·합계 수식 여부, 입력값 수식 혼입, 차감 음수, 블록 순서, 병합·숨김·그룹, 검증 블록 존재)을 검사한다. 계정과목이 원본 표기와 같은지는 사람이 원본과 대조한다.
