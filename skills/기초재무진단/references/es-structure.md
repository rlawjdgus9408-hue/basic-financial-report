# Executive Summary — 구조·작성 패턴·표기

> SKILL.md STEP 5(Q5-1~Q5-12)에서 참조한다. 사실검증·톤 규칙은 `es-verification.md`.

## Q5. Executive Summary 작성

**분량 제한: A4 1페이지 최대. 3단락 구성 권장 (4단락은 양호 영역이 다수일 때만 분리).**

### Q5-1. 3단락 사고 구조 + 불릿 5개 출력 (Director 표준)

| 단락 | 역할 | 핵심 질문 | 판정 문장 종결 |
|---|---|---|---|
| 1 | **회사 분석** | 회사는 어떤 상태이며 무엇이 일어났는가 | ~로 진단됩니다 / ~로 판단됩니다 |
| 2 | **인사이트** | 데이터에서 도출된 본질적 통찰은 무엇인가 | ~로 평가됩니다 / ~확인됩니다 |
| 3 | **운영 관리 측면의 보완사항** | 향후 운영에서 보완이 요구되는 지점은 | ~보완이 필요합니다 / ~필요한 시점으로 보입니다 |

확장 4단락 패턴 (양호 영역이 단락 1~2에 압축되지 못할 때만):
- 단락 1: 회사 분석 / 단락 2: 인사이트 / 단락 3: 주요 사항 (재무 안정성·자본 구조·운전자본) / 단락 4: 보완사항

**★ 위 종결 표현은 "판정하는 문장"에만 적용한다.** 위치(첫 문장·마지막 문장)가 기준이 아니라 문장의 성격이 기준이다. 정체성 정의·해석·판정 문장에는 판정 종결을, **사실 서술에는 단정 종결**을 쓴다 (했습니다 / 입니다 / 없습니다 / 차지합니다 / 넘습니다).

Director 완성본 실측 예 — 정체성 정의가 첫 문장인데 판정 종결이 붙었고, 나머지는 단정이다.
```
① ...인력을 조직해 마진을 붙이는 BM으로 판단됩니다.   ← 정체성 정의 = 판정 종결
② 2025년이 첫 온전한 회계연도인데, ...함께 냈습니다.   ← 사실 = 단정
③ 총자산은 3.9억으로, ...매출을 만드는 사업입니다.     ← 사실 = 단정
```

모든 문장에 판정 종결을 붙이면 `[명사]로 + 피동 종결`이 반복되어 기계적인 글이 된다. 판정 종결은 단락마다 다르게 변별하고, "필요합니다" 패턴 반복은 금지.

**★ 출력 형식: 사고는 3단락, 출력은 불릿 5개.**

`<종합의견>`은 표 안의 한 칸이라 줄글 세 덩어리를 넣으면 벽처럼 보인다. 위 3단락 사고 구조를 유지하되 **`▪` 불릿 5개로 분해해 출력**한다.

| 불릿 | 담는 내용 | 대응 단락 |
|---|---|---|
| ▪1 | 회사 정체성 + 당기 실적 + 자산 구조 | 1 앞 |
| ▪2 | 재무 안정성 + 성과 인정 + 다음 과제 | 1 뒤 |
| ▪3 | 비용 구조의 본질 (원가·비용 분리 여부 등) | 2 앞 |
| ▪4 | 핵심 리스크 (쏠림·편중) + 규명 필요 사항 | 2 중 |
| ▪5 | 보완사항 2~3줄 | 3 |

- **불릿당 150~185자**로 편차를 줄인다. 한 불릿이 다른 불릿의 2배를 넘으면 분할한다.
- 불릿 안에 메시지가 둘 이상이면 불릿 내부에서 줄바꿈한다 (▪1·▪5가 해당).
- 불릿이 개수를 보여주므로 **"보완할 지점은 둘입니다" 같은 개수 예고 문장은 쓰지 않는다.**

### Q5-2. 단락 1 (회사 분석) 작성 패턴 ★ Director 핵심

**첫 문장은 반드시 "회사 정체성"으로 시작한다.** 매출·이익 수치로 시작 금지.

- ✗ 잘못: "(주)○○○는 매출이 27.6억에서 104억으로 376% 증가, 영업이익도 1.9억에서 6.5억으로 동반 확대된 고성장 단계의 기업입니다."
- ✓ 올바름: "(주)○○○는 사업 실질은 [업종 정의]가 손익을 견인하는 사업 모델로 판단됩니다. 3개년 동안 매출이 27.6억에서 104억으로 376% 증가, 영업이익도 1.9억에서 6.5억으로 동반 확대된 고성장 단계의 기업입니다."

업종 정체성 정의 우선순위:
1. 사업자등록상 분류와 실질이 다를 경우 **"실질" 정의** 우선
2. 매출 구성에서 손익 견인 축을 우선 표기 (제품 vs 공사 vs SW)
3. 회사소개서·등록증 등 보조자료에서 핵심 사업 키워드 추출

### Q5-3. 분석 → 시사점 연결 (각 단락 마무리 1줄) ★

각 단락은 사실 종결로 끝내지 않고, **"향후 무엇이 중요한가"를 명사형 1줄로 추가**한다.

| 단락 | 마무리 시사 패턴 |
|---|---|
| 1 (회사 분석) | "~이 부분에 대한 확장 혹은 효율 증대에 대한 고민이 시작되는 시점으로 판단됩니다" |
| 2 (인사이트) | "~효율성 유지가 향후 손익 관리의 핵심 요인으로 보입니다" |
| 3 (보완사항) | "~보완이 필요한 시점으로 보입니다" |

명령형 금지 ("~필요합니다" 단독 사용 X). 헤지형 ("~시점", "~보입니다") 허용.

**중간 문장은 단정, 마무리 1줄만 헤지.** 이것이 Director 패턴이다. 사실 문장을 헤지로 끝내면 진단이 흐려지고, 마무리를 단정으로 끝내면 지시형이 된다.

**★ 적자·부실 원인 단정 회피 (Director 패턴)**

Level 3 지표(이자보상배수 1배 미만 등)라도 ES에서 **"[단일 지표]가 [적자·부실]의 배경/원인으로 평가됩니다"식 단정 인과를 걸지 않는다.** 적자 원인은 대개 복합적이며, 단일 지표를 주범으로 못박으면 오진이 된다.

- ✗ 잘못: "이자보상배수가 1배를 밑돌았습니다. 영업이익만으로는 이자 부담조차 감당하지 못하게 되었고, 이는 2025년 적자 전환의 배경으로 평가됩니다." (실제 적자 주범이 외환손실인데 이자를 주범으로 단정)
- ✓ 올바름: "부채 총량이 유지됨에 따라, 고금리 국면에서 영업이익 대비 이자비용이 관리 가능한 수준으로 발생하고 있는지 지속적인 점검이 필요합니다." (지표는 짚되 인과 단정 대신 점검 필요로 전환)

Director는 인과를 단정한 문장을 삭제하고 **"~관리 수준으로 발생하고 있는지 체크 필요"** 형태의 헤지로 교체한다. 단, **재무제표 셀 코멘트에서는 확인된 수치 인과(예: "외화환산손실 전환으로 당기순손실")는 단정 유지** — ES와 셀 코멘트의 톤은 분리한다.

### Q5-4. 압축 우선순위 (양호 vs 문제·기회)

**양호 영역은 한 줄로 압축, 문제·기회는 구체적으로.** Director는 핵심 시그널 집중을 위해 노이즈를 제거한다.

| 영역 유형 | 작성 분량 |
|---|---|
| 양호한 영역 (운전자본 안정, 정합성 확보 등) | **한 줄로 압축** ("운전자본 등도 양호한 상황으로 진단됩니다") |
| 변화·전환 영역 (외형 폭증, 사업 구조 전환) | 수치 3~5개 동반 구체 기술 |
| 보완·리스크 영역 | 수치 + 의미 + 시사 1줄 |

세부 데이터(자본금 1.5억 유상증자 + 이익잉여금 누적 8.2억 등 괄호 구성 / DSO 1.7일 / CCC 38.2일 등)는 **본문 표로 위임**, ES에서 제거.

### Q5-5. 추상 분석 용어 회피 ★

학술·분석학 용어는 ES에서 제거. 구체 사실 또는 시사로 대체.

| 금지 표현 (학술적) | 대체 표현 (구체적) |
|---|---|
| "이익의 질" | (해당 문장 자체 삭제 또는 사실 기술로 대체) |
| "매출 mix 개선" | "공사 부문이 손익을 견인" |
| "매출 주도형 성장" | (인사이트에 통합, 단독 평가 문장 금지) |
| "구조적 전환" | "사업 구조 전환" (이미 사실인 경우만) |

### Q5-6. 재무관리 체계 관점 (체크리스트 ↔ ES 연결) ★

부문별 재무진단 결과(사전 검토사항 10개 항목) 중 **"개선 필요" 응답 비중이 높으면 (5개 이상) ES 보완사항 단락에 재무관리 체계 도약 관점을 1줄 추가**한다.

예시:
> "회사의 성장에 따라 월단위의 손익과 자금을 모니터링 할 수 있는 재무Report 체계와 재무계획을 통한 예산/리스크 관리 등 재무관리 체계도 한 단계 도약이 필요한 시점으로 보입니다."

연결 로직:
- 매월 재무성과 보고 X → "월단위 재무Report 체계"
- 재무계획·예산 X → "재무계획을 통한 예산/리스크 관리"
- 재무 리스크 대응 X → "재무관리 체계 도약"

체크리스트 결과와 ES가 단절되면 본문 부문별 진단의 의미가 약해진다.

### Q5-7. 보완사항 항목 수

운영 관리 측면 보완사항은 **2가지만 언급**한다 (번호 부여 ①②③ 금지, 자연어 연결).

- 1가지: 가장 두드러진 보완 지점만 언급할 때
- 2가지: 본업 수익성 + 재무관리 체계 등 영역이 다를 때
- 3가지 이상: ES 분량 초과, 본문으로 위임

해결 방법 상세 서술 금지. "~분해 / ~점검 / ~정립" 등 액션 동사는 본문 부문별 진단에 위임. ES에서는 **"~보완이 필요합니다"로만 마무리**.

### Q5-8. 화살표 사용 제한 ★

ES 전체에서 비율 변동 화살표(X%→Y%)는 **최대 2개**.

권장: 인사이트 단락의 시소 메커니즘 (예: 매출총이익률 34.7%→21.7%, 판관비율 27.9%→15.4%)

나머지 비율 변동은 자연어로 변환:
- "182.4%에서 125.7%로 3년 연속 개선" (✗ 182.4%→125.7%)
- "3.4배에서 15.6배로 확대" (✗ 3.4배→15.6배)
- "65.3%에서 78.3%로 상승" (✗ 65.3%→78.3%)

### Q5-9. 단위 표기 (한국식 옵션 B 표준)

ES 코멘트의 금액 단위는 한국식 "억+천만" 통일.

| 금액대 | 표기 방식 | 예시 |
|---|---|---|
| 1억 이상 + 천만 단위 있음 | "X.X억" 소수점 1자리 | 538백만원 → 5.4억 / 150백만원 → 1.5억 |
| 1억 이상 + 천만 단위 없음 | "X억" 정수 | 800백만원 → 8억 |
| 1000만~1억 미만 | "X천Y백만" | 78백만원 → 7천9백만 |
| 1000만 미만 | "X백만" or "X천만" | 12백만원 → 1천2백만 |

세부 만/십만 단위는 절삭. 표의 셀에는 정확 금액이 명시되므로 코멘트는 가독성 우선.

### Q5-10. 영어 약어 한글화 (필수)

ES에서 영어 약어 사용 금지. 한글 정식 명칭 사용.

| 약어 | 한글 명칭 |
|---|---|
| GPM | 매출총이익률 |
| OPM | 영업이익률 |
| NPM | 순이익률 |
| DSO | 매출채권 회수기간 |
| DIO | 재고자산 회전일수 |
| DPO | 매입채무 결제기간 |
| CCC | 현금전환주기 |

ROA·ROE는 한국 실무에서 그대로 사용하나, 한글 병기 권장 ("ROA(자산이익률)").

### Q5-11. ES vs 본문 역할 분리

| 구분 | ES 역할 | 본문 (표·차트) 역할 |
|---|---|---|
| 핵심 메시지 | ✓ 전달 | – |
| 수치 | 핵심 5~10개만 | 전체 데이터 |
| 세부 구성 (괄호) | ✗ 제거 | ✓ 표로 전달 |
| 차트 | – | ✓ 메시지 강화 2~3개 |

ES가 본문의 축소판이 되지 않도록 분리. ES는 **"읽는 문서"**, 본문은 **"확인하는 문서"**.

**★ 단락 간 동일 수치 반복 금지 (Director 패턴)**

동일 핵심 수치(재고자산회전일수·현금전환주기·부채비율 등)를 **2개 이상 단락에서 반복하지 않는다.** 한 수치는 ES 전체에서 1회만 좌표로 사용한다.

- ✗ 잘못: 2단락에서 "재고회전일수 956일, 현금전환주기 968일"을 제시하고, 보완사항 단락에서 다시 "재고회전일수 956일과 현금전환주기 968일로 나타났습니다"로 반복.
- ✓ 올바름: 2단락(인사이트)에서 수치를 1회 제시하고, 보완사항 단락에서는 수치 재인용 없이 **재무관리 체계 관점(월단위 Report update, 리스크 관리 체계 도입 등)으로 교체**하여 마무리.

보완사항 단락이 인사이트 단락의 수치를 재나열하면 ES가 늘어지고 Director는 이를 삭제한다. 보완사항 단락은 **수치가 아니라 "체계·방향"으로 닫는다** (Q5-6 재무관리 체계 관점과 연결).

**★ 보완사항은 "방법"과 "대상"을 특정한다 (Director 교정 지점).**

무엇을 하라는지 없는 보완사항은 문장일 뿐 액션이 아니다. 방법(어떤 체계로)과 대상(무엇을 나눌지)을 각각 한 단어씩 박는다.

| 초안 | Director 완성본 | 추가된 것 |
|---|---|---|
| 원가 구조를 먼저 확정해야 합니다 | **관리회계 기반의 변동비(원가)** 구조를 먼저 확정해야 합니다 | 방법=관리회계 / 대상=변동비 |
| 예산 관리도 함께 갖출 시점입니다 | **재무계획에 의한** 예산 관리도 함께 갖출 시점입니다 | 방법=재무계획 |

액션 동사의 상세 서술은 여전히 본문에 위임하되, **명사구 수준의 방법·대상 특정은 ES에서 한다.**

### Q5-12. 공통 규칙

- 첫 문장: "공유해 주신 데이터를 근거로 하면" 또는 "회사 정체성 정의"로 시작
- 단락당 4~5문장 이내
- 전체 글자 수 약 700~1,000자 (3단락 기준). 사용자가 분량을 지정하면 그에 맞추고, 늘릴 때는 여백이 아니라 내용으로 채운다
- **한 단락이 전체 분량의 40%를 넘으면 분할하거나 압축**
- 불릿 5개 출력 시 **총 800~900자, 불릿당 150~185자**가 Director 실측 기준 (완성본 847자)
- **단락 마무리 3개 종결을 서로 다르게 쓴다.** 중간 문장은 능동·단정이므로 종결 가짓수를 인위적으로 늘리지 않는다
- **자가점검: 피동 종결(`~됩니다` 계열) 비중이 전체 문장의 30%를 넘으면 재작성.** 3단락 20~27문장 기준 피동 종결 3~6개가 정상. 종결 형태가 6종 이하로 반복되면 기계적인 글이다

문단 공식 (Fact → Diagnosis → Impact → Control):
"[수치 대비 Fact], [판정 Diagnosis]. [현금/마진/런웨이 영향 Impact]. [관리 체계 방향 Control]."

금지 표현 (ES): "착시", "도산", "부재", "폭발적", "사상 최대", "~시사합니다", "~가능성이 있습니다", "~하세요", "이익의 질", "매출 mix", "매출 주도형 성장", 영어 약어 (GPM·OPM·NPM·DSO·DIO·DPO·CCC)
